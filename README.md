# 计划表 — 手机网页 App（PWA）

本地优先的计划表 + 课程表应用。无需登录、无后端，数据全部保存在手机本地。

## 功能一览

**计划**
- 计划增删改查、完成打卡、按分类分组（工作 / 学习 / 生活 / 自定义，可增删）
- 优先级（高 / 中 / 低）、重复计划（每天 / 每周 / 工作日）、到点浏览器通知提醒
- 今日页顶部有当日进度条

**考试 / 活动**
- 固定日期 + 开始结束时间 + 地点的活动（如考试），支持颜色标记与到点提醒
- 显示在今日页「考试 · 活动」区和日历的日视图里

**日历**
- 月视图：有安排的日期打点，点日期看当天全部计划 / 课程 / 活动
- 计划与课程自动合并到每一天，按时间排序

**课程表**
- 周课表网格（5 个大节 × 7 天），点课程块编辑、＋ 手动添加
- 课程持续时段两种设置方式：全学期 / 从某天开始持续几周（自动换算周次）/ 直接填起止周
- **导入课表**：
  - 粘贴文本（如 `高等数学 周一 1-2节 教一A101`），逐行解析，识别失败的行标红
  - Excel 文件（.xlsx / .xls）：自动识别星期表头行和节次列，支持“课程名/教室/周次”混排与纵向合并的连堂课，识别结果可勾选导入
- **调课 / 调休**：取消某周某次课、把某周课程临时调到另一天某节次（原时间腾空）、额外补课；调整集中在列表里可随时删除
- 学期设置（名称 + 第 1 周周一日期）

**统计**
- 本周完成率（只统计已过去的日子）、连续打卡天数、近 7 天完成数柱状图

**其他**
- 深色模式：跟随系统自动切换，也可手动固定
- 数据导出 / 导入（JSON 备份文件）、清空数据
- PWA：可添加到手机主屏幕（图标 + 全屏运行），长按图标快捷打开「今日待办」，离线可用

## 本地运行

```bash
npm install
npm run dev        # 开发调试，默认 http://localhost:5173
npm run build      # 构建产物到 dist/（含 PWA manifest 与 Service Worker）
npm run preview    # 本地预览构建产物
npm run icons      # 重新生成 PWA 图标（public/pwa-192.png、pwa-512.png）
```

## 在手机上使用

1. 电脑与手机连同一网络后 `npm run dev -- --host`，手机浏览器访问提示的地址；
   或者把 `npm run build` 产出的 `dist/` 部署到任意静态托管。
2. 手机浏览器菜单 →「添加到主屏幕」，即可像 App 一样全屏使用。
3. 数据仅保存在当前设备浏览器里：换设备或清浏览器数据前，先用「我的 → 数据导出」备份。

## 说明与边界

- **提醒**：App 打开（前台）期间每 30 秒检查一次，临期弹浏览器通知（需授权）。
  系统级推送需要服务端，纯本地版不含；页面关闭时提醒不工作。
- **桌面小组件**：PWA 受系统限制做不了真正的系统桌面小组件（一期提供主屏幕图标 +
  长按快捷方式）。如必须真小组件，二期可用同一套代码经 Capacitor 打包 Android APK。
- **喜鹊儿等课表 App 导入**：它们没有公开接口，无法直接对接；请使用粘贴文本导入或 Excel 导入。
- 目录里的 `ui-mockup.html` 是开发前的 UI 设计示意图，可双击直接在浏览器打开。
- `样例课表.xlsx` 是一份可用来试 Excel 导入功能的示例文件。

## 部署

**主入口：GitHub Pages**（推送即自动构建部署，无需手工操作）。

```bash
git push        # 推送到 GitHub 后，.github/workflows/deploy-pages.yml 自动构建并发布 dist/
```

- 线上地址：`https://<用户名>.github.io/plan-app/`
- 构建用了 `base: './'` 相对路径（vite.config.js），所以放在任何子路径下都能跑，
  hash 路由不依赖服务器配置。
- 国内访问 `github.io` 目前可用但偏慢（首屏 0.3~2.4s），且属"半通"状态；
  好在是 PWA，**添加到主屏幕后走离线缓存，之后不再依赖网络**。

**备用入口：腾讯 EdgeOne Makers**（国内边缘节点，秒开；默认域名仅 3 小时预览链接，
长期公开需绑定自有域名）。

```bash
npm run build
npx edgeone@latest makers deploy dist -n testapp-qibbv2s0   # 已登录后直接覆盖
```

- 项目 ID：`makers-wujibrm`（项目名 `testapp-qibbv2s0`，已认领到腾讯云账号）
- 生成 API Token 后可无人值守部署：`npx edgeone@latest login -t <token>`。

## 技术栈

Vue 3（`<script setup>`）+ Vite + vue-router（hash 模式）+ vite-plugin-pwa；
无 UI 框架，样式为 CSS 变量主题化手写；数据层为 localStorage（`src/stores/storage.js` 统一读写，预留云同步替换点）。
